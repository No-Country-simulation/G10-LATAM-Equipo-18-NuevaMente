# Oracle Cloud Infrastructure Networking

## Virtual Cloud Network (VCN)

A VCN is a private, customizable network configured in Oracle Cloud
Infrastructure, similar to a traditional data center network.

### Subnets

A VCN is divided into public and private subnets. Public subnets allow
instances to have a public IP; private subnets do not.

## Security Lists

Security Lists act as virtual firewalls at the subnet level, defining
which traffic is allowed in or out through ingress and egress rules.
